# 【书刊7】 源惑认知陷阱的生成语法

> 学术·认知

## 关于本书

人类认知有一条奇怪的裂缝：极擅长找模式，却系统性地把相关当因果、把幸存者当全体、把事后可解释当事前可预测。本书讨论这道裂缝的生成语法：幸存者偏差、辛普森悖论、回归均值、伯克森悖论、事后归因等陷阱各配生成机制、历史案例与识别检验。理论底座是珀尔的因果推断革命——do-演算把因果从形而上学变成可操作的数学对象。
